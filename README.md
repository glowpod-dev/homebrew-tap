# Glowpod Homebrew tap

```bash
brew install glowpod-dev/tap/glowpod
```

Installs `glowpod` for macOS and Linux (Intel and ARM): the Kubernetes dashboard in your browser (`glowpod`) and in your terminal (`glowpod term`).

`Formula/glowpod.rb` is written by the release workflow of [glowpod-dev/glowpod](https://github.com/glowpod-dev/glowpod) on every release. Don't edit it here. Website: https://glowpod.dev
